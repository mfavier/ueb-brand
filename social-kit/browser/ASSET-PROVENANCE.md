# Actifs de production — Atelier UEB

Ce dossier accompagne le moteur navigateur de l’atelier intégré au Manager.
Il contient uniquement les actifs d’identité utilisés pour les publications.

- `ueb-logo.svg` et `ueb-logo.png` : blason officiel Uccle Europe Basketball,
  provenant de `ueb-brand/src/logos/uccle-europe.svg`. Le SVG conserve son contenu
  exact et ses proportions ; SHA-256 :
  `9037f430905f4d33a05a843468ba9b3cc318a74f46d791b9b3a7f8eeab2456bf`.
- `decorative/ueb-crest-*.svg` : dérivés monochromes des tracés officiels pour les
  arrière-plans. Leur provenance complète est conservée dans
  `decorative/PROVENANCE.md`. Ces matières ne remplacent pas le blason identifiant.
- `fonts/Kanit-Bold.ttf`, `fonts/Kanit-ExtraBold.ttf` et
  `fonts/DM-Sans-Variable.ttf` : polices du kit de marque. Leurs licences SIL Open
  Font License sont fournies dans `fonts/Kanit-OFL.txt` et `fonts/DM-Sans-OFL.txt`.

Les photos illustratives, archives, exemples fictifs et leur documentation restent
dans le kit de marque complet. Ils ne sont pas embarqués dans ce paquet de
production. Les photos et logos sélectionnés dans le Manager sont des ressources
éditoriales distinctes, conservées dans le stockage privé des brouillons.
