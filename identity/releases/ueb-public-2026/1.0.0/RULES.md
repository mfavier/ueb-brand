# Identité publique UEB · 2026 · 1.0.0

Référence de communication issue du site public 2026, officialisée comme version
explicite pour les nouvelles productions. Les déclinaisons sociales existantes
ont déjà cette palette ; leur migration technique vers ce registre est séparée.

Utiliser les couleurs exactes de tokens.json, Kanit pour les titres et DM Sans
pour la lecture. Bleu nuit, blanc et bleu ciel dominent ; l’or sert d’accent.
Préserver les proportions et les couleurs du blason officiel. Les versions de
fond sont des dérivés décoratifs distincts. Les photographies gardent leur
contexte et leurs crédits. Employer les photos du club dont l’usage est validé.

Titres directs, information hiérarchisée, mise en page aérée. Les documents ont
leurs propres règles de lecture A4 : corps 11 pt minimum, tableaux lisibles,
pagination et références utiles. La taille sociale de 40 px ne s’applique pas.
La signature peut être utilisée dans son ordre exact, sans être systématique.

Les exemples ne fournissent aucun chiffre, tarif, contact ou engagement réel.
Les données factuelles et commerciales doivent être validées et datées.

Cette release est figée après fusion : ajouter une nouvelle release pour toute
bascule graphique. Un ancien document continue de demander son id/version exacts.
